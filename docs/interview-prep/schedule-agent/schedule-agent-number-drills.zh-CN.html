🎯 意图打分（⚠️ 易错，别答成"给模型"）

意图识别用模型还是规则？
规则 + 关键词打分，零 LLM（route.py 的 _calculate_intent_score）。
打分规则大概怎么加减分？
命中 trigger_phrases +12 / 各意图关键词 +16~40 / 冲突信号 −30~−40。
confidence 是怎么来的？是模型概率吗？
_score_to_confidence 把规则分数阶梯映射（score≥30→0.95 / ≥24→0.90…），不是模型概率。
什么时候触发 need_clarify？
confidence<0.5 或 top1/top2 分差过小 或 写操作置信度<阈值。
