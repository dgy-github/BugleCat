# 模型厂商、模型目录与费用展示设计

## 目标

让 nanocodex 的设置页能够按厂商选择模型，并在选择时同时配置正确的接口、模型标识和费用估算参数。用户不需要记忆不同厂商的接口地址，也不会出现选择了一个厂商模型却仍向另一个厂商接口发送请求的情况。

目录覆盖常用直连厂商，并通过 OpenRouter 的公开模型接口覆盖其全量聚合模型。费用显示保留原始币种；本地估算仅作为参考，厂商账单仍是最终依据。

## 范围

### 首批直连厂商

- DeepSeek
- 阿里云百炼（千问与百炼托管模型）
- 火山方舟（豆包）
- 智谱 AI
- 月之暗面 Kimi
- MiniMax
- OpenAI
- Gemini 的 OpenAI 兼容接口
- OpenRouter

上述“直连”仅表示该厂商提供或支持 OpenAI Chat Completions 兼容接口，并可由当前运行时协议调用。Anthropic 原生 API 不在本期伪装成直连厂商；Claude 等模型可经 OpenRouter 使用，原生 Anthropic 适配另行设计。

### 不在本期范围内

- 自动兑换人民币与美元，避免引入不稳定的汇率数据；费用使用厂商原始币种显示。
- 代替用户创建、充值或验证第三方 API Key。
- 以静态清单穷举 OpenRouter 的全部模型。
- 支持图片、音频、视频等非文本计费的本地精确估算。

## 数据模型

新增共享的模型预设目录。每个预设包含：

- `provider_id`：稳定的厂商标识。
- `provider_name`：中文厂商名。
- `model_id` 与 `display_name`：实际请求模型标识和展示名称。
- `base_url`：兼容接口地址。
- `price_in`、`price_out`：每百万 Token 的输入、输出价。
- `price_currency`：`CNY` 或 `USD`。
- `source_url` 与 `updated_at`：官方价格来源和目录更新时间。
- `direct_available`：是否可由当前 OpenAI 兼容运行时直接调用。

预设目录只收录每家厂商适合编程智能体的近期主力、经济与推理模型，不把已下线或仅适合图像/语音的模型混入文本选择器。每个价格均以官方页面为依据，并在源代码中保留来源链接与更新时间。

OpenRouter 不写入上述静态全量目录。程序通过其公开 `/api/v1/models` 接口取得模型 ID、展示名、上下文长度、能力和价格；将每 Token 的美元价格转换为每百万 Token 的展示值。刷新失败时保留本次会话最近一次成功结果，并显示可理解的失败提示。

## 配置兼容

配置文件新增可选键 `price_currency`。旧配置没有该键时默认为 `CNY`，确保原有 `price_in`、`price_out` 行为不变。

选择厂商预设时一次性保存并重新加载：

- `model`
- `base_url`
- `price_in`
- `price_out`
- `price_currency`
- `available_models`

用户可选择“自定义 / 兼容 OpenAI 接口”，此模式不自动改写接口和价格。用户手动覆盖价格或接口后，也保留覆盖值，直到再次明确选择一个厂商预设。

顶部模型快速切换改为使用同一个预设应用入口；切换模型时不得只改 `model` 而遗留旧的 `base_url` 或价格。

## 界面与交互

设置页按以下顺序展示：

1. 厂商选择器，包含“自定义 / 兼容 OpenAI 接口”。
2. 与厂商联动的模型选择器；显示模型类别、模型 ID 和上下文信息（有数据时）。
3. 价格卡：输入与输出每百万 Token 单价、币种、目录更新时间，以及“查看官方价格”链接。
4. 接口地址与 API Key；预设选中后地址自动填入，仍可查看。
5. “手动覆盖价格”开关。未开启时价格字段只读；开启后用户可修改价格和币种。

选择 OpenRouter 后显示“刷新模型列表”、名称搜索和按价格/上下文排序。刷新不需要 API Key；若网络不可用，显示已缓存的结果或提示用户可使用自定义模型 ID。

会话页的累计费用显示使用 `price_currency`：人民币显示 `¥`，美元显示 `$`。当价格未知或为零时仅显示 Token，不显示虚假的费用。

## 错误处理

- 缺少 API Key：保留现有“去设置”引导，不把工作线程退出。
- OpenRouter 网络或数据格式错误：不影响已选择模型与手动配置；给出中文提示。
- 用户选择本期无法直连的模型：禁止应用预设，并说明可通过 OpenRouter 使用。
- 厂商价格具有缓存、长上下文、批量或媒体等阶梯：价格卡明确标记“本地估算，以官方账单为准”，并链接官方页。

## 验收与验证

- 目录单元测试验证每个预设的模型、接口、价格、币种和官方链接均完整。
- 配置测试验证 `price_currency` 能读写且旧配置默认人民币。
- 后端测试验证应用预设会成组更新模型、接口和价格；自定义模式不会被覆盖。
- OpenRouter 解析测试覆盖正常数据、空价格与网络失败后的缓存降级。
- 前端构建和界面回归测试验证厂商—模型联动、币种显示和价格覆盖交互。
- 不使用真实密钥或真实付费调用进行自动化测试。
